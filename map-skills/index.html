Five map parts: title, compass rose, legend/key, scale, and grid.

Remember the jobs: compass rose = direction; legend/key = symbols and colors; scale = map distance compared with real distance; grid = helps locate places.

Map types: reference maps show locations; thematic maps show specific information; political maps show government boundaries; physical maps show natural features.

Elevation clues: contour lines connect places at the same elevation. A topographic map uses contour lines to show elevation.

A map: a drawing or picture showing the relative size and position of features on Earth.
